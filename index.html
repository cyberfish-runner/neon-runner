玩法特色

霓虹冲刺

按住 Shift + 方向键触发，约 115px 的瞬时位移、1 秒冷却。可以跨越宽深坑，但绝不会穿墙。单独按 Shift 没有任何作用。

二段跳

空中再按一次跳跃。两段合计最高约 171px（和早期的「向上突进」等高），落地即恢复，用来救场或微调落点。

数据贫民窟 → 霓虹城区 → 企业高塔，三套配色、三套视差背景、共 99 枚芯片，通关后有一段制作名单结局。

常见问题

点标题展开

安装时弹出「Windows 已保护你的电脑」，怎么处理？

这是正常现象，不是病毒。因为本程序没有购买商业代码签名证书，Windows SmartScreen 对「没有签名 + 下载量还很少」的程序会默认拦截。

处理办法：

  1. 在弹出的蓝色窗口里，点左边的「更多信息」；
  2. 右下角会多出一个「仍要运行」按钮，点它；
  3. 安装向导就会正常打开。之后再次运行不会再拦。

如果连「更多信息」都点不出来，或被杀毒软件直接隔离：把安装包所在目录加入杀软白名单（360 / 火绒 / Windows 安全中心 都有「信任区 / 排除项」），或者从隔离区里恢复该文件。

安装版和便携版有什么区别？

安装版：双击安装、自动建桌面和开始菜单快捷方式、可在系统里正常卸载，适合长期玩。

便携版：单个 exe 文件，拷到 U 盘或任意文件夹双击就能玩，不写注册表、不建快捷方式，适合临时试玩或换电脑。

两者内容完全一样，存档也是共用的（都在 %APPDATA%\NeonRunner\）。

游戏存档在哪？卸载会丢吗？

存档在：%APPDATA%\NeonRunner\Local Storage\leveldb\

（在文件资源管理器地址栏直接粘贴这一行就能打开，%APPDATA% 会自动展开。）

卸载不会删除存档——重新安装后进度还在。想彻底清空进度，手动删掉整个 %APPDATA%\NeonRunner 文件夹即可。

需要联网吗？会不会偷偷连网？

完全不需要联网，游戏没有任何联网功能：没有广告、没有统计上报、没有自动更新检查。

断网状态下可以正常游玩全部内容。程序体积大（约 106 MB）是因为内置了完整的浏览器运行时，不是因为有联网资源要下载。

双击后一闪而过 / 没有窗口，怎么办？

按可能性从高到低排查：

  1. 被杀毒软件拦截了：查看杀软隔离区，恢复文件并加入信任区。
  2. 系统是 32 位或 Windows 7/8：本游戏只支持 64 位 Windows 10（1809+）/ Windows 11。
  3. 下载不完整：用上面的 SHA256 校验一下，不一致就重新下载。
  4. 显卡驱动太旧：更新显卡驱动；或在程序快捷方式后加 --disable-gpu 参数再试。
支持 macOS 或 Linux 吗？

目前只发布了 Windows 版。游戏引擎本身是跨平台的，macOS 版的主要工作量在于苹果的签名与公证流程（需要 Apple 开发者账号），后续会考虑。

临时想在 Mac / Linux 上玩，可以先用网页版的 在线试玩。

在线试玩和下载版有什么不同？

内容完全一样，是同一份游戏。

在线版需要键盘（手机、平板没有实体键盘就没法操作），而且存档保存在浏览器里——清理浏览器数据会丢。

下载版有独立窗口、支持 F11 全屏、存档存在 %APPDATA% 更稳妥，体验更好。
